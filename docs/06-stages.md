# 06. ステージ（全 5 面・実装値）

定義は `src/data/stages.ts`。味方の配置は `src/data/party.ts`（灯火のミラ (-14,-20)／宵闇のレン (0,-23)／均衡のソウ (14,-20)）が既定で、**面ごとに `Stage.allyPositions` で上書きする**（`createBattleState` が適用）。**#69 で全 5 面が上書きを持ち、味方は大きく散開する**（下表）。敵は上方、味方は下方。
**難易度の枠組み（LVL・数値スケール・解放表）は [06b-difficulty-framework.md](06b-difficulty-framework.md)**。本ファイルは実装されている配置・数値の一覧。
障害物の素材は `solids`（重なった円の和＝連続ブロブ）と `rects`（軸並行の矩形＝四角い壁・#56）で表す。`R=2.4`（円の半径）、`STEP=2.4`（円の間隔）。柱・瓦礫は円、壁・ブロックは矩形（角がシャープ）を使う。

## #69 のレイアウト設計原則（全面に機械的に課す）

想定プレイ時間 15〜30 分に合わせて **7 面 → 5 面**へ集約し、1 面＝1 つの学習テーマにした。地形は「RPG のダンジョンの部屋」に寄せ、以下を `stages.test.ts` の describe「レイアウトの一般則（#69）」で固定している。

| 原則 | 内容 | テストでの固定 |
|---|---|---|
| 直線を通さない | **第1面以外は、どの味方からどの敵へも直線が通らない**（必ず遮蔽が挟まる） | 全味方 × 全敵の線分が素材に触れる |
| 味方は散開 | 相互距離 ≥10・横幅 ≥18・前後差 >2（横一列に並べない） | 面ごとに検査 |
| 結界の余地 | 各味方の周囲**半径 7.5 に素材が無い**（結界は壁に触れると霧散するため・#34） | 第2面以降 |
| 迂回型は陰に | attacker は最寄り味方への直射線が遮蔽で塞がれる（曲射だけが届く） | 第2面以降の全 attacker |
| 火力型は守護の内側 | breaker は守護型／ボスから **≤6**（`enemyGuardRadius−1`）＝結界に覆われる | guardian/boss がいる面 |
| 暴発型は半身を隠す | ruptor は至近 8 以内に遮蔽を持つ | 全 ruptor |
| 攻め手は必ず残す | 敵 → 各味方に**素材に触れない経路が存在する**（＝敵AIが曲げて攻撃できる） | 第2面以降 |
| 内部の壁は硬い | 戦術壁・柱は `tough`（数撃かけないと崩れない） | 面ごとに本数の下限 |

### 直線を断つ「三列の千鳥列柱」の幾何

等間隔の柱をピッチ **12** で並べ、**列ごとに 1/3 ピッチ（=4）ずつ横へずらして三列**置く。柱の直径 `2R=4.8` は `12/3=4` より大きいので、三列の影が横方向で必ず重なる＝**どの縦線も必ずどれか 1 本に当たる**。一方で同じ列の柱どうしは `12−4.8=7.2` 空いており、曲げれば素材に触れずに抜けられる車線が残る。斜めの射線は柱だけでは塞ぎ切れないので、崩落壁・塔・盾を足して塞ぐ（実測で確認）。

**壁配置（部屋モデル）**：各面は「**円の中に壁で囲った部屋**」。円の外周と部屋の間を `unbreakable` の壁で埋め、部屋の中で戦う（`chamber` / `roomWalls`）。四方を囲うので側面の回り込みは起きない。第1面は部屋で囲うが `mechanics.obstacles=false`＝囲いは装飾（当たり判定なし）。

**ステージのサイズ（場の広さ）**：`rFieldForSize(size)=round(25+(size-1)·35/3)`（size1→25, 1.5→31, 2→37, 2.5→43, 3→48, 3.5→54, 4→60）。**第1面=最小25**、**最大＝第5面②=60**。大アリーナでも弾が対岸へ届くよう、回転方式のサンプリング上限 `rotateXMax` は `max(48, 1.6·fieldR)` と `fieldR` に追従する（`coords.ts`）。盤面は**ズーム/パン**で見やすくできる（`BattleCanvas`）。

共通：`castInitialSpeed=8`（既定。唯一の例外は第4面の崩し手3体＝`6.5`・#63）。HP は基礎 100 × LVL 倍率（`LVL_SCALE`。明示 `hp` があればそちら）。`castMag` も LVL 依存（[06b](06b-difficulty-framework.md) §2）。

## 障害物のヘルパー（`src/data/stageBuilders.ts`）

| 関数 | 形 |
|---|---|
| `pillar(cx, y0, n, element, kind?)` | 縦の柱（上へ n 個の円・丸い） |
| `block(x0, y0, cols, rows, element, kind?)` | 四角いブロック（cols×rows ぶんを覆う矩形・#56） |
| `wall(x0, x1, y0, rows, element, kind?)` | 横一列の四角い壁（rows 段ぶんの厚みの矩形・#56） |
| `roomWalls(xL, xR, yB, yT, rField)` | **部屋の囲い**：円の中に矩形の部屋を残し、外側を `unbreakable` の壁で埋める。角は場境界の外まで伸ばして密封 |
| `chamber(xL, xR, yB, yT, rField, doors?, element?, kind?)` | **ドア（開口）つきの部屋**（#69）。各辺に `{center, width}` の開口を空けられる＝部屋どうしが扉で繋がるダンジョンを組める |
| `pillarGrid({x0,x1,nx,y0,y1,ny,r?,element,kind?,skip?})` | **等間隔の柱グリッド**（#69）。`element` は `(ix,iy)=>...` で格子ごとに切替可。要素ごとに 1 つの Obstacle へまとめる |
| `ruinedWall(x0, x1, y, rows, element, kind?, {gaps?,gapCount?,seed?})` | **崩れ落ちた壁**（#69）。開口を明示するか、`seed` から決定的にばらけた欠けを作る |
| `brokenColonnade(x0, x1, step, y0, maxRows, element, kind?, seed?)` | **折れた列柱**（#69）：柱ごとに高さがばらつく崩れかけの神殿 |
| `rubble(cx, cy, spread, n, element?, kind?, seed?)` | **瓦礫の山**（#69）：半径のばらついた小塊を散らす（既定 `fragile`） |
| `brokenTower(cx, cy, w, h, element, kind?, {tallSide?,seed?})` | **壊れた塔**（#69）：片側だけ高く残った建造物＋足元の瓦礫（`[塔, 瓦礫]` を返す） |
| `colonnade(x0, x1, step, y0, n, elems[], kind?)` | 列柱（step 間隔で縦 n 段の柱を並べる） |
| `spiralArm(cx, cy, n, turns, phase, element, r0=2.5, kind?)` | アルキメデス螺旋の腕 |
| `disc(cx, cy, r, element, kind?)` | 単一の円ブロブ（岩塊。崩し手のカバー） |
| `rng(seed)` | 決定的な擬似乱数（mulberry32）。**`Math.random` は使わない**（同じ seed なら常に同じ地形＝テストが揺れない） |

`mechanics`：`obstacles`（障害物有効か）・`enemyFire`（敵が撃つか）の段階的解禁。

### 断末魔（暴発3連・撃破の最終演出）

- ボス HP が 0 になっても勝敗は確定せず（`finale='pending'`）、**次のターンにボスが暴発型3連の「最後の一手」を晒して放つ**（`finaleVariant`＝role: ruptor・castCount: 3・`ruptorTarget: 'allies'`）。
- 3本とも**通常ルールの弾**：反対極の結界・パリィで速度0にすれば暴発せず、`instability` も積まない。防げなかった分は通常の暴発（常に最大威力・両極性）＋ `instability +1`（最大+3）。
- このタイミングで `instability` が上限（12）に達すれば、**ボス撃破後でもステージ全体暴発＝ゲームオーバー**（免除なし）。
- 3本を解決したのちに勝敗判定へ進む（`finale='done'` → クリア）。

### ボスの多段外見（`bossView`・#51）

フェーズ（`bossPhase` 0/1/2）・断末魔（`finale`）・撃破確定（`outcome='cleared'`）に応じて `drawBossSprite`/`drawBossCollapse` が段階変化する。詳細は [07-animation.md](07-animation.md) §「ボスの多段外見と最終崩壊」を参照。
