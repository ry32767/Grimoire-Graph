# 08. 定数リファレンス

すべてのバランス数値は `src/data/constants.ts` に集約（ロジックにハードコードしない方針）。
演出の定数は各描画ファイルにある（§末尾）。

## FIELD（フィールド・物理）

| 定数 | 値 | 意味 |
|---|---|---|
| `rField` | 30（既定） | 場外境界（原点からこの半径外は場外＝暴発/消滅）。**面ごとに `Stage.rField` でスケール**（サイズ由来。第1面25〜第5面②60・[06-stages.md](06-stages.md)） |
| `sMax` | 5 | 属性強度の最大値 |
| `zPeak` | 5 | 強度ピーク V（|z|=zPeak で強度最大の山型） |
| `epsilon` | 0.35 | 中立しきい（\|z\|<ε は中立） |
| `aMax` | 13 | 加速度上限（\|z\|≈0 で最大加速・中立が最速） |
| `zRef` | 2.5 | 加速度基準（\|z\|=zRef で加速度 0、超えると減速） |
| `aDecelMax` | 8 | 減速の上限（負の加速度の頭打ち） |
| `dt` | 1/60 | 積分ステップ（秒） |
| `fixedSpeed` | 10 | 初速（毎回固定） |
| `maxFlightSpeed` | 24 | 飛行速度の上限（終端速度） |
| `aoeRadius` | 5 | 暴発の AoE 半径 |

> 設計の肝：`zRef(2.5) < zPeak(5)`。最強属性を狙うほど減速し、速度 0 で霧散する精度ゲームになる。

| `breakerRampPow` | 2 | 火力型のランプ z 場のべき：`z=極性×zPeak×(d/L)^これ`。飛行中は中庸で加速し命中直前に zPeak（05b §5.1） |

## RUPTOR（崩し手・#42／[05b-enemy-archetypes.md](05b-enemy-archetypes.md) §4）

z 場に極（1/x 型の特異点）を仕込み、狙点で暴発させる敵の z 場パラメータ。
`z(x,y) = zBase×極性 + poleK/g(x,y)`（`g` は狙点で 0 になる接近方向の符号付き距離）。

| 定数 | 値 | 意味 |
|---|---|---|
| `zBase` | 2.2 | 飛行区間の基礎 z（zRef 以下＝自然失速しない範囲で、属性がはっきり読める強さ） |
| `poleK` | 2 | 極の強さ係数。大きいほど手前から z が急峻になり、減速域が広がる（迎撃猶予は増える） |
| `ringFrontMargin` | 1.6 | 結界を狙うときの「リング迎撃範囲の手前」マージン（#48・05b §4）。極を `ringRadius＋この厚み` だけリング中心から手前（敵側）に置き、弾自体は迎撃を受けずに AoE を内側へ届かせる。`ringRadius＋margin ≥ aoeRadius`（半径5）になる大きな結界では奥へ届かないため補正せず、真位置を狙って通常の迎撃に委ねる |
| `wallFrontMargin` | 1.8 | 壁の奥に隠れた味方を狙うときの「壁面の手前」マージン（#42・05-enemies §5.4b）。敵→対象の直線が素材に阻まれるとき、極を「最初に素材へ触れる地点」よりこの距離だけ敵側へ引く（`wallFrontAim`）。手前で暴発させれば弾は壁に阻まれず極まで達し、削れる壁なら AoE が壁も崩す（封印帯を「確実に積む」）。補正はリング手前補正の後に適用する |

## ENEMY_ROUTE_PLANNING（敵AIの経路計画・`enemyPlanning/`）

迂回型（attacker）・暴発型（ruptor）が「幾何経路探索 → family フィット → 本番物理検証」の3層（[05-enemies.md](05-enemies.md) §5.4/§5.4b）で軌道を選ぶときの調整パラメータ。

| 定数 | 値 | 意味 |
|---|---|---|
| `gridStep` | 0.75 | 経路探索のグリッド幅（ユニット）。`rField=30〜36` で実用的なノード数に収まる |
| `maxExpansions` | 12000 | A* の展開ノード数上限（暴走防止） |
| `smoothingPasses` | 3 | 経路平滑化（見通し線ショートカット）のパス数 |
| `clearance` | 0.45（`max(0.45, OBSTACLE_STEP×0.75)`） | クリーン経路に要求する余白（ユニット）。本番判定より少し広く取り、フィット誤差・弾の太さでも「素材に触れない」を実際に保証する。`OBSTACLE_STEP` に自動追従 |
| `materialWeight` | 40.0 | 経路探索で素材（削れる壁）を通るときの距離あたり追加コスト（`wallTunnel` モード） |
| `maxGoalsPerEnemy` | 6 | 1体あたりの経路探索ゴール数上限（`ruptor` の壁狙い個体が試す素材セル数） |
| `maxRoutesPerGoal` | 4 | 1ゴールあたりの採用経路数上限（定数として定義済み。現状 `fitRouteToFamilies` は family 数（≤3）しか候補を返さないため未到達） |
| `maxTunnelLength` | 8.0 | 壁トンネル（直線掘削）の最大長（ユニット）。これより長い掘削は諦めて牽制へ |
| `maxTunnelCount` | 1 | 1経路あたりの壁トンネル本数上限（壁内部の蛇行禁止） |
| `monotoneBacktrackEps` | 0.35 | family フィットで局所 x の後退を許す上限（ユニット）。超えると回転方式で表現できない経路として棄却 |
| `wideClearance` | 1.5 | **広い車線を優先するための余白**（#69）。まずこの余白で経路を探し、無ければ通常の `clearance` で探し直す。柱の隙間の中心を通る経路が得られるので、フィット誤差があっても素材に触れない＝**一度触れただけで失速する弾でも通せる** |
| `harmonicMaxTerms` | 5 | `harmonic`（多重サイン）フィットの項数上限（#69）。基底 `sin(kπx/L)` は `g(0)=g(L)=0` を厳密に満たす＝必ず狙点で終わる。大きいほど細い隙間を縫えるが、うねりが激しくなり壁の内側で折り返しやすい |
| `harmonicRidge` | 0.02 | `harmonic` フィットの平滑化（リッジ）係数（#69）。高周波の項ほど強く罰する（`λ·k²`）ことで、「通過点は通るが暴れる」過適合を避ける |

## INSTABILITY（暴発の不安定化・累積・崩壊・04b）

「膜の摩耗」＝ラン全体（全5面通し）で累積するカウンター。暴発が解決するたび +1（味方でも敵でも同じ）。

| 定数 | 値 | 意味 |
|---|---|---|
| `firstCollapseThreshold` | 5 | この暴発回数で初回崩壊（グリモワールの介入・一度きり） |
| `firstCollapseStage` | 4 | 初回崩壊の保証面（1始まり）。遅くともこの面のターン2以降で必ず発生（#69：5面構成の封印帯＝第4面） |
| `misfireLimit` | 12 | 致死しきい：この回数で破局（ステージ全体暴発＝ゲームオーバー・救済なし） |
| `vStart` | 4 | 半径ばらつきの開始 count（＝misfireLimit×1/3。崩壊まで残り2/3 からブレ始める） |
| `vMax` | 0.6 | 半径ばらつきの最大（実半径 = aoeRadius×(1±v)） |
| `relief` | 1 | 暴発ゼロでステージクリア時の緩和（−1・下限0） |

## RECOMMEND（おまかせ照準の探索・[03-functions.md](03-functions.md) §3.5）

壁のある面で強い z（zPeak/zRef）だと削りコストが高く壁の奥へ届かない。弱い z と狙い角の振りを足し、貫通/迂回して当たる（無理なら対象へ最も近づく）経路を探す。

| 定数 | 値 | 意味 |
|---|---|---|
| `zWeak` | 1.5 | 壁貫通向けの弱い属性強度（\|z\|）。zRef 未満＝飛行中減速せず削りコストも小さい |
| `angleOffsets` | `[0, ±0.2, ±0.4]` | 狙い角のオフセット候補[rad]（壁ありの面のみ。隙間や貫通できる入射角を探す） |
