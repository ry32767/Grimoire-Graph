## 0. 全体方針

- **2ビュー体系**：PC（幅 > 820px）とスマホで同じ情報を別レイアウトで出す。PC は並列表示、スマホは「盤面を残して下からせり出す」。
- **盤面は常に主役**：全フェーズで盤面 canvas を表示。UI は盤面を隠さない（スマホのログはドロワー、編集はボトムシート）。
- **戦闘ログは全フェーズ常設**：敵公開（開戦直後）からアクセス可能。位置は PC=盤面右上タブ、スマホ=上部バー右端。
- **1画面1つの gold**：そのフェーズで最も重要なアクションのみ gold ボタン（DESIGN.md §4.2）。

|---|---|---|---|---|

| 2 | 作成（コマンド一覧） | `compose` | ✓ | ✓ |
| 3 | 術式編集（軌道/z場） | `compose`（編集中） | ✓ | ✓ |

## 1. 敵公開フェーズ（enemyReveal）

**目的**：このターン敵が撃つ「形」を読ませる。操作は確認のみ。

### PC レイアウト

```
┌─ rwin.arena (h:440) ────────────────────────┐
│ [グリフ◠]                        [戦闘ログ▾]│ ← ログタブ(右上常設)
│ [敵名バッジ+敵HPバー]                        │
│   敵スプライト                               │
│   ゴースト軌道(紫破線)                       │
│         盤面グリッド+座標軸+原点             │
│   味方スプライト ×3                          │
└──────────────────────────────────────────────┘
┌─ rwin.pc-footer ─────────────────────────────┐
│ ヒント文(系統・属性の推測)      [術式を構える▸]│ ← gold
└──────────────────────────────────────────────┘
```

### 要素仕様

| 要素 | 仕様 |
|---|---|
| 系統グリフ | 敵頭上の丸枠（26px・notch・鋼青）。記号は family 対応：直進=╱ 弧=◠ 波=〜 渦=◎ 折れ=∨ 昇り=⤴ 捻れ=∿（暫定。確定は 05-enemies の glyph 定義に従う） |
| ゴースト軌道 | `--dark` の破線（stroke 3・dash 4 4・opacity 0.7〜0.85）。敵の予告軌道 |
| 敵名バッジ | 黒地半透明＋鋼青1px縁。敵HPバーは `--dark` フィル＋セル目地 |
| ヒント文 | フッター左。「◯◯は「弧」を放つ気配 ／ 属性は闇寄りと推測される」形式 |
| 進行 | gold「術式を構える ▸」→ 作成フェーズへ |

### スマホ

- 上部バー：左=ステージ/ターン表記（`第一章・T1／敵公開`）、右=「戦闘ログ ▾」。
- ログは上から**ドロワー**で開閉（盤面を潰さない・max-height 120px・縦スクロール）。
- 盤面 h:320。下に全幅 gold「術式を構える ▸」。

## 2. 作成フェーズ（compose・コマンド一覧）

**目的**：古典RPGの「コマンド選択」。ここから おまかせ／術式編集／発射 に分岐。

### PC レイアウト

```
┌─ rwin.arena (h:400) ─────────────── [戦闘ログ▾]┐
│  敵(グリフ+名+HP) / ゴースト軌道(紫破線)       │
│  自分の狙い軌道(金実線) / 味方3人(編集中=金)   │
└────────────────────────────────────────────────┘
┌─ cmd-win (200px) ─┬─ status-win (1fr) ─────────┐
│ ▶ ◆ おまかせ      │ タイトル行(章/ターン/フェーズ)│
│   ✎ 術式を組む    │ ◎ 灯火のミラ [HP====] 135/135│
│   ◎ 全員発射      │ ・ 宵闇のレン [HP====] 135/135│
│                   │ ・ 均衡のソウ [HP====] 150/150│
└───────────────────┴─────────────────────────────┘
```

### 要素仕様

| 要素 | 仕様 |
|---|---|
| コマンド窓 | 縦リスト＋▶カーソル（`--cursor`）。項目：おまかせ（=recommendAll）／術式を組む／全員発射。アイコンは鋼青 |
| ステータス窓 | grid `16px 76px 1fr 34px 60px`。準備状態：◎（設定済み・hp-ok）／・（未設定・dim）。HP数値は VT323 |
| 「術式を組む」選択 | コマンド窓＋ステータス窓が**引っ込み**、同じ場所に詠唱ウィンドウ（§3）がせり出す（排他表示） |
| 全員発射 | 未設定の味方がいる場合は確認を挟む（#49 `confirmFire`） |

### スマホ

- 盤面 h:300 → ステータス窓（コンパクト grid `14px 44px 1fr 46px`）→ コマンド3ボタン横並び（◆おまかせ｜✎術式｜◎発射=gold）。
- **味方行タップ or「✎術式」**でボトムシート（§3）が下からせり出す。
- 発射後は盤面ビューに戻る（#48）。

## 3. 術式編集（詠唱ウィンドウ）

**目的**：複雑な編集（プリセット→式→係数→フィット→z場）を、段階的開示で圧迫なく行う。

### 共通構造（PC=下部ウィンドウ / スマホ=ボトムシート）

```
┌ msg-header: 「宵闇のレン ・ 術式を詠唱」          ✕もどる ┐
├ subtabs: [軌道] [z場（属性）]                              ┤
├ subpane（タブごと）                                        ┤
│  preset-row: ╱ ◠ 〜 ⤴ ∨   （選択=鋼青枠）                │
│  expr-box:   0.25(x−8)² − 6      ← 整形表示(VT323 24px)   │
│              y = 0.25*(x-8)^2-6  ← 生の式(16px dim)        │
│  expr-editrow: [入力欄(VT323)] [適用]                       │
│  fitbar: [点を選ぶ（フィット）] [盤面でθを決める]           │
│  adv: 係数を調整 ▸ →（開くと）a/h/k スライダー              │
├ msg-actions: [キャンセル] [詠唱を確定(gold)]                ┤
└─────────────────────────────────────────────────────────────┘
```

### 盤面（編集中）

- **敵を必ず表示**：敵スプライト＋名前＋HP＋ゴースト軌道（紫破線）を盤面上部に出し、狙いながら編集できる。
- 自分の狙い軌道は `--light` 実線＋着弾点マーカー。
- z場タブ選択中は盤面に z 場オーバーレイ（金/紫の radial・薄く）。

### 軌道タブ

| 要素 | 仕様 |
|---|---|
| プリセット | 形アイコンで選択（直線╱ 放物線◠ サイン〜 指数⤴ 絶対値∨）。選択で式を自由入力欄へ転記（03-functions §3.3 のフロー） |
| 式表示 | 二段（整形＋生）。整形規則：`*`省略、`-`→`−`、`^2`→`²`（表示のみ・入力は生の式） |
| 点を選ぶ | §4 点フィットモードへ遷移（盤面が主役になる） |
| 盤面でθ | 盤面クリックで発射方向を決める（#47）。作成中は金の矢印表示 |
| 係数 | 「係数を調整 ▸」に**畳む**（初期非表示）。スライダーは `--cursor` アクセント、値は VT323 |

### z場タブ

| 要素 | 仕様 |
|---|---|
| プリセット | ■一定 ↕縦勾配 ↔横勾配 ◎放射 |
| 式表示 | 二段（`z = 4.6` 等） |
| **z強度ゲージ** | 山型 SVG（頂点=zPeak）。現在値マーカー（光=金四角/闇=紫四角）＋「現在：光・強度4.6（高いが失速しやすい）」の1行注釈。**このゲームの核（山型強度と失速のトレードオフ）を常時可視化するシグネチャ** |
| 盤面で調整 | スマホは「盤面で属性を調整」ボタン→全画面盤面＋文脈バー（#54） |

### スマホ差分

- ボトムシートとして開閉（開いている間もコマンド行は隠れるが盤面は見える）。
- 整形式は 20px に縮小。fitbar は「点を選ぶ／θを決める」の短縮ラベル。

## 4. 点フィットモード（fitPick）

**目的**：通過点を盤面に直接打って軌道をフィットさせる（#54「盤面で完結」）。

```
┌─ rwin.arena (PC h:440 / SP h:400・全画面主役) ┐
│  破線プレビュー軌道(金) / 打点(pick-dot ×n)   │
│  自分+敵スプライト                             │
└────────────────────────────────────────────────┘
┌─ fitmode-bar ──────────────────────────────────┐
│ 「盤面に点を打ってください（2点選択中）」        │
│              [クリア] [やめる] [フィット(gold)] │
└────────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| pick-dot | 8px 角・`--cursor`＋濃縁。打った順序がフィットの通過順（#50） |
| 文脈バー | 選択数を明示。フィット=gold。「やめる」で詠唱ウィンドウへ戻る |
| モード排他 | fitPick 中は通常の盤面アクション（θ設定等）を無効化（01 §#54 `data-mode`） |

## 5. ステージエディタ（DEV・PC専用）

**目的**：壁・敵・味方を CAD/PowerPoint 的に視覚編集し、その場でテストプレイ（11-stage-editor 準拠）。
スマホでは案内文のみ（「PC でご確認ください」）。

### レイアウト（grid: `1fr 264px` × `auto 1fr auto`）

```
┌─ cad-ribbon（全幅）──────────────────────────────────────────┐
│ ツール[▣選択|▭壁|●円|◐削る|⌫消去]  配置[敵|味方]            │
│ 素材[通常|もろい|頑丈|不壊]                                   │
│        …spacer…  [初期instability[0]] [▶テストプレイ(gold)]  │
│                              [リセット] [書き出し▾]           │
├─ cad-stage ───────────────────────────┬─ cad-right ──────────┤
│ ┌20px定規(上/左・VT323目盛)┐          │ ┌ステージ────────┐  │
│ │ 盤面: グリッド+軸+       │          │ │ LVL[1]           │  │
│ │  rField境界円(真円)      │          │ │ rField ▬▬●▬ 25   │  │
│ │  十字カーソル+座標(-6,3) │          │ │  推奨/範囲表示    │  │
│ │  壁(sel=鋼青+4隅ハンドル │          │ │ mechanics[select] │  │
│ │     warn=橙 / 削り跡)    │          │ ├オブジェクト(7個)─┤  │
│ │  敵/味方スプライト        │          │ │ ▦部屋・左   👁✕  │  │
│ │  [＋|－|⤢]ズーム(右下)   │          │ │ ▦壁A(頑丈)*選択  │  │
│ └──────────────────────────┘          │ │ ▭柱B(警告)  …    │  │
│                                        │ ├プロパティ:壁A──┤  │
│                                        │ │ x,y,w,h / 属性    │  │
│                                        │ │ 種別 / 複製|削除  │  │
│                                        │ │ 部屋の囲い:四方|左右│ │
├─ cad-status（全幅・VT323）────────────┴──────────────────────┤
│ カーソル x:-6 y:3 | スナップ 1.0 | 選択 壁A | 種別 tough | ズーム100% │
└──────────────────────────────────────────────────────────────┘
```

### 要素仕様

| 要素 | 仕様 |
|---|---|
| ツールパレット | 選択/壁(矩形)/円/**削る(carve)**/消去 ＋ 敵配置/味方配置。選択中=鋼青ハイライト |
| 素材 | normal／fragile（もろい）／**tough（頑丈）**／unbreakable（不壊）。壁の見た目：通常=土色、もろい=薄赤紫・細枠、頑丈=青緑・太枠、不壊=灰青 |
| 定規・座標 | 上/左 20px 定規（ゲーム座標目盛・VT323）。十字カーソル＋座標リードアウト |
| rField | **スライダー**（範囲 18–60・推奨値表示）。境界円は**真円**（px指定・aspect-ratio 1/1）で即時連動。円外オブジェクトは `--warn` 表示（11 §5） |
| 選択・編集 | 選択壁=鋼青＋四隅リサイズハンドル。重なり=橙＋警告バー。ドラッグ=粗調整、プロパティ数値=微調整（11 §4.3） |
| オブジェクト一覧 | 行=アイコン+名前+👁(表示切替)+✕(削除)。選択行=鋼青、警告行=橙 |
| テストプレイ | リボン右。**初期 instability 入力欄を直前に併置**（テストプレイ専用設定・11 §7）。gold |
| 書き出し | TS コード片／JSON（11 §9）。ドロップダウン |
| リセット | インライン確認を挟む（11 §8） |

## 6. レスポンシブ規則

| 項目 | PC (>820px) | スマホ (≤820px) |
|---|---|---|
| 情報配置 | 並列（盤面＋下部2窓） | 縦積み＋せり出し |
| 戦闘ログ | 盤面右上タブ→パネル重ね | 上部バー→ドロワー |
| 術式編集 | 下部ウィンドウ（排他） | ボトムシート |
| 点フィット | 盤面拡大＋下部バー | 全画面盤面＋下部バー |
| コマンド | 縦リスト＋▶ | 横3ボタン |
| エディタ | フル機能 | 非対応（案内のみ） |
| タップ領域 | — | ボタン高 ≥36px・行タップで編集へ |

## 7. 状態とフィードバック

| 状態 | 表現 |
|---|---|
| 選択/フォーカス | 鋼青（`--cursor`）枠 or ▶ |

## 8. 受け入れ条件（UI）

- [x] 全フェーズ（敵公開含む）で戦闘ログを開ける（PC=右上タブ／SP=ドロワー）― 2026-07-10：`.log-tab`/`.log-panel`（`BattleLog.tsx`）。敵公開フェーズも `revealed=false` の UI 専用ゲートで追加済み

- [x] 係数スライダー・詳細設定は初期状態で畳まれている ― `FunctionPanel.tsx` の「詳細設定 ▸」disclosure
- [x] z場タブに山型の強度ゲージが表示され、現在値と注意文が出る ― `ZFieldControls.tsx` の `ZStrengthGauge`
- [x] 数式は整形表示＋生の式の二段で表示される（フォントは VT323）― `.expr-pretty`/`.expr-raw`（`--expr` トークン。実フォントは未同梱、下記フォント課題参照）
- [x] gold ボタンは 1 画面につき原則 1 つで、そのフェーズの最重要アクションに一致する ― 敵公開＝「術式を構える」、点フィット＝「フィット」、詠唱＝「詠唱を確定」相当

- [x] 盤面（床）に背景画像がなく、グリッド・座標軸・原点が明瞭に見える ― `draw.ts`
- [x] rField 境界円が真円で、スライダーと即時連動する ― `draw.ts`（既存実装）
- [x] エディタ：素材4種（通常/もろい/頑丈/不壊）が選択・表示・プロパティで一貫している ― 2026-07-10：`.cad-ribbon` の素材パレット（色スウォッチ付き）で選択、新規壁の種別に反映。プロパティ/ステータスバーにも表示

- [x] エディタ：重なり・境界外が橙で警告される ― `.stage-editor-warning`（`--warn`）＋重なりマークの橙点線
- [x] スマホ：ログドロワー／ボトムシート／点フィット全画面が動作し、盤面が常時見える ― ログはドロワー化・術式編集はボトムシート相当（`view==='edit'` の msg-win）。点フィットは全画面までは簡略化（下記参照）
- [x] スキャンライン・pixelated が全画面に適用されている（設定で無効化可能）― 既存実装（`body::after`／`image-rendering:pixelated`）
